## Inhalt des Entwurfs

- **Hero** mit Klick-Treffern: Ein Klick ins Feld (auch auf den Text) hinterlässt einen Farbtreffer
- **Anlässe:** Kindergeburtstag, Firmenevent, JGA, Turnier, Vereinssport, Urlaub & Ausflug
- **Preise** für Erwachsene und Kids, dazu ein **Gruppenrechner**, der das Anfrageformular vorausfüllt
- **Ablauf**, **Galerie**, **Gutscheine**, **Häufige Fragen**
- **Anfrage** mit eigenem Kalender, Auswahllisten und Personenzähler (Versand im Entwurf simuliert)
